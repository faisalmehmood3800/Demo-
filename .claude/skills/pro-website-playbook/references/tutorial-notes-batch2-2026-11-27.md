## G. hqsB5XI0Wis "It took me 3+ years to realize what I'll tell you in 23 minutes" (23m, read fully) = LinkedIn sales machine
- Presenter claims Rs 40 lakh revenue in 2 months / $1 lakh in 6 months from LinkedIn (his claims, unverified). Ends with a paid masterclass promo (skip).
- Five mistakes: generic profile (headline/about/banner show no credibility or proof); not enough content, random posts, no strategy (goal is leads and sales, not likes; can work with few followers); too few cold DMs, or DMs that are pushy/salesy; no market research, no clear ICP (industry, age, income, pain points); doing everything by hand, nothing automated.
- 5-step "LinkedIn sales machine":
  1. Perfect prospect: don't target everyone; only people who need and can pay: companies recently funded, hiring, or posting requirements; connect with decision-makers who have authority, not low-level staff.
  2. Instant authority (profile): professional photo, clear lighting; headline = who you help + what you deliver + time frame (+ price), e.g. "Helping founders build their AI product in 30 days within $10k"; can niche further ("healthcare founders"); banner minimal with credibility: client logos, review counts, numbers; About: start with big (true) numbers, storytelling, your process for that type of client; experience, education, projects filled in.
  3. Right content that sells: value posts, not random; frameworks like PAS (problem, agitate, solution); weekly content calendar (e.g. Monday value post, Tuesday testimonials/reviews); add stats and client stories; ~20% of posts end with a clear call to action, after the story, not 100%.
  4. Attract, don't chase (inbound): valuable comments on ICP people's posts (summarise, add your unique perspective, or add a point they missed); 3-4 good comments on one person's posts -> they DM you; free webinars/sessions; referrals. When someone DMs, never hard-sell: ask what they do and their problems, give free value first; high-ticket ($1k-5k) deals take weeks.
  5. Automation: AI to summarise long posts, draft comments (10 min -> 2 min, you still edit), find content ideas; later AI outreach that scrapes ICP profiles and personalises your templates; CRM to track who was contacted, followed up, replied, closing.
- My caveat: only real numbers/logos/reviews (agency-offer-playbook rule); automated LinkedIn scraping/outreach can break LinkedIn's terms and get the account restricted: keep volume low and personal.

## J. qF0NqK91Qqw "N8N Full Course: Building AI Agents (Urdu/Hindi)" (1h12m, read fully)
- n8n vs Make: n8n more flexible (custom code), chosen. Automation = trigger -> fixed action -> result (pre-written instructions, no judgement). Agent = trigger -> AI action that reads and decides at run time (e.g. order email -> decide shoes vs shirts department).
- Five node kinds explained: trigger (click, form, button, email, order), action (Gmail, Drive, Calendar, WhatsApp, Telegram...), utility (filters/IF, e.g. order > $1,000 also alerts the owner; summaries), code (e.g. split one address field into address/city/postcode), agent (the brain).
- n8n Cloud 14-day trial; projects; templates (2,000+) useful later, learn from scratch first.
- Agent 1 "smart email responder": Gmail trigger (On message received, poll every minute; credential via Sign in with Google) -> Text Classifier with categories + descriptions (Order: email mentions a new order; Inquiry: customer asks a question) -> each branch OpenAI "Message a model" (gpt-4o-mini, cheap) prompt "act as copywriter and my Gmail assistant, reply to this email: {{ $json.snippet }}", ask for two parts (subject line, body), output content as JSON, simplify output off for long emails -> Gmail "Create draft" (subject + message mapped) so a human reviews before sending. Test by sending emails from a second account; "Execute previous nodes". Lesson: AI left "[Customer Name]" because the name wasn't passed in: pass every field the reply needs.
- Agent 2 "mobile-accessories inventory": Chat trigger -> AI Agent -> OpenAI chat model (API key from platform, prepaid credits; never share the key) + Simple Memory (no memory = forgets "my favourite bike is Ducati"; context window length 5 messages; more = more cost; session ID comes from the chat trigger, for Telegram/WhatsApp map the chat ID) + Airtable tools. Airtable base built by its AI (products, price, quantity; added min-quantity field). Personal access token with scopes (records read/write, schema read) + base access.
  Tools: Search records (description "search the Airtable"), Update record with $fromAI: record ID ("find the exact id of the item"), new price (number), new quantity (number); types matter (number vs string). Test: "bought 200 new covers" -> 150 -> 350 verified in the table.
  Pitfall: vague message "all items stock bought 300" set EVERY item to 300 instead of adding: agents take sloppy instructions literally -> system message must say add vs set, and confirm before bulk updates.
- Business: look at problems around you (shops, friends' industries), automate, sell (e.g. inventory agent for mobile shops; voice/WhatsApp front end later).
